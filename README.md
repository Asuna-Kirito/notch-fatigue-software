# 焊缝缺口应力疲劳分析

海洋立管环焊缝疲劳寿命分析软件（Windows 版发布包）。本仓库只提供发布包，不含源代码。

## 下载

在右侧 **Releases** 中下载对应版本的 `NotchFatigue_v版本_win-x64.zip`（Windows 64 位）。

## 功能

- 读入 ANSYS 导出的焊趾单位载荷应力和 OrcaFlex 焊缝截面内力时程
- 按 IIW 有效缺口应力法（焊趾虚拟圆角 r = 1 mm）逐节点计算疲劳寿命
- 自动判别单轴、剪切、比例和非比例多轴状态并选用对应评定方法
- 内置 IIW、DNV-RP-C203 的空气、海水、阴极保护、自由腐蚀 S-N 曲线，可存入试验曲线
- 寿命云图、圆周分布、危险节点、单节点逐步计算书、三维显示、工况对比、试验对比
- 导出 Excel 与 Word 报告

## 运行环境

- Windows 10（1809 及以上）或 Windows 11，64 位，Intel 或 AMD 处理器
- 内存 4 GB 以上（软件本身约 150～300 MB），硬盘 1 GB 以上
- 不需要安装 Python 或其他运行库

## 使用

1. 解压到任意文件夹（路径可以有中文），双击 `焊缝缺口应力疲劳分析.exe`。
2. 软件内“帮助”页为技术手册，任何页面按 F1 打开对应章节。
3. 卸载：运行程序文件夹中的 `卸载.cmd`，或直接删除程序文件夹。软件不写注册表。

第一次计算时计算内核需要编译，会多用几十秒，之后有缓存。

# 输入文件格式

## 1. OrcaFlex 焊缝截面内力时程（载荷页）

一个文件是焊缝所在截面的一条时程记录，CSV 或 TXT，逗号、制表符或空格分隔，UTF-8 或 GBK 编码均可。

| 量 | 识别的列名（不区分大小写，开头匹配） | 单位 |
|---|---|---|
| 时间 | `Time`、`t`、`时间` | s（列对照中可选 min、h） |
| 剪力 Fx | `Fx`、`x shear` | kN |
| 剪力 Fy | `Fy`、`y shear` | kN |
| 轴力 Fz（壁张力） | `Fz`、`wall tension`、`tension` | kN |
| 弯矩 Mx | `Mx`、`x bend` | kN·m |
| 弯矩 My | `My`、`y bend` | kN·m |
| 扭矩 Mz | `Mz`、`torque` | kN·m |
| 有效张力（可选） | `effective tension`、`Te`、`有效张力` | kN |

- 列名中带单位时自动换算，如 `Fz (N)`、`Mx_kNm`、`My (N m)`；识别不了单位时按 kN、kN·m 处理，可在 **列对照…** 中改。
- 轴力用**壁张力**（wall tension），拉为正；不要用有效张力代替。
- 剪力和弯矩是 OrcaFlex 线单元局部坐标系中的分量，局部 z 轴由 A 端（上端）指向 B 端（下端）。ANSYS 模型的 z 轴须同向、右手系、拉为正；
  绕管轴的转角不需要对应，只影响危险点在圆周上的位置，不影响最小寿命。
- 时间必须单调递增；个别空行会被丢弃，空值超过 1 % 时报错。
- 只有“时间、力”两列的文件按单轴试验机记录读入（轴力为第二列，其余分量为 0）。

示例（`示例数据/示例载荷_焊缝截面.csv` 的前几行）：

```
Time_s,Fx_local_kN,Fy_local_kN,Fz_wall_kN,Mx_local_kNm,My_local_kNm,Mz_torque_kNm
0.0,0.1291,2.5946,1480.234,8.1709,2.4192,0.1371
0.2,0.3235,3.2012,1483.925,4.6175,2.5396,0.2012
```

## 2. ANSYS 导出文件（新建模型）

由随软件提供的 Mechanical 脚本生成，放在同一个文件夹（默认桌面 `FAT_ANSYS`），新建模型时选这个文件夹。

| 文件 | 来源 | 内容 |
|---|---|---|
| `STEP_01_time_1.csv` … `STEP_12_time_12.csv` | 04 号脚本 | 每个载荷步评定面节点的 6 个应力分量：`body_id,node_id,SX,SY,SZ,SXY,SYZ,SXZ`（MPa，坐标系 local） |
| `export_info.txt` | 04 号脚本 | 导出设置、约束位置、焊缝截面位置 |
| `nodes_xyz.csv` | 05 号脚本 | 节点坐标（mm） |
| `surface_facets.csv` | 05 号脚本 | 表面面片（三维显示、表面法向） |
| `mesh_quality.csv`、`export_info_mesh.txt` | 05 号脚本 | 网格尺寸统计（数据检查） |
| `weld_profile_nodes.csv` 等 | 07 号脚本 | 焊缝子午截面（三维显示、几何核对），可选 |

要求：

- 评定面是焊趾 1 mm 圆角面（命名选择 `FAT`），应力为节点平均值，同一模型各载荷步的节点集合相同。
- 管段模型：A、B 两端各 6 个单位载荷（力 1 kN、力矩 1 kN·m），载荷步结束时间为 1～12 s，顺序见 ANSYS 脚本说明。
- 坐标系 `local`：z 沿管轴，原点在管轴上。

自定义模型可以在新建模型对话框中逐步指定每个载荷步的施加位置、分量、方向、大小和对应的结果文件。

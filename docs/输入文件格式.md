# 输入文件格式

## 1. OrcaFlex 焊缝截面内力时程

在载荷页“导入表格”或直接拖入窗口。CSV、TXT 或 Excel，逗号、制表符、分号或空格分隔，UTF-8 或 GBK 编码均可；
表头前可以有说明行，表头下可以有单位行。一个文件可以只有一个截面，也可以有多个截面。

| 量 | 识别的列名 | 单位 |
|---|---|---|
| 时间 | `Time`、`t`、`时间` | s，列对照中可选 min、h |
| 剪力 Fx | `Fx`、`x shear` | kN |
| 剪力 Fy | `Fy`、`y shear` | kN |
| 轴力 Fz | `Fz`、`wall tension`、`tension` | kN |
| 弯矩 Mx | `Mx`、`x bend` | kN·m |
| 弯矩 My | `My`、`y bend` | kN·m |
| 扭矩 Mz | `Mz`、`torque` | kN·m |
| 有效张力，可不提供 | `effective tension`、`Te`、`有效张力` | kN |

- 一个文件多个截面时，列名写成“截面名 + 分量 + 单位”，例如 `上段中点_13m_Fx_xShear_kN`，或 OrcaFlex 原生的
  `Riser: Wall Tension at 13.0m` 加单位行。软件去掉分量词和单位后剩下的文字为截面名；含“中点、焊缝、weld、mid”的为焊缝截面，
  含“上端、下端、top、bottom”的为两端截面，数字加 m 为弧长。文件名开头的块号（如 `F4_…`）记为海况。
- 列名不区分大小写。列名中带单位时自动换算，例如 `Fz (N)`、`Mx_kNm`、`My (N m)`；识别不了单位时按 kN、kN·m 处理，可以在列对照中修改。
- 轴力用壁张力 wall tension，拉为正，不要用有效张力代替。
- 剪力和弯矩是 OrcaFlex 线单元局部坐标系中的分量，局部 z 轴由上端 A 指向下端 B。ANSYS 模型的 z 轴须同向，右手系，拉为正；
  绕管轴的转角不需要对应，它只影响危险点在圆周上的位置，不影响最小寿命。
- 时间必须单调递增；个别空行会被丢弃，空值超过 1 % 时报错。
- 只有时间和力两列的文件按单轴试验机记录读入，第二列为轴力，其余分量为 0。

`示例数据/示例载荷_焊缝截面.csv` 的前几行：

```
Time_s,Fx_local_kN,Fy_local_kN,Fz_wall_kN,Mx_local_kNm,My_local_kNm,Mz_torque_kNm
0.0,0.1291,2.5946,1480.234,8.1709,2.4192,0.1371
0.2,0.3235,3.2012,1483.925,4.6175,2.5396,0.2012
```

## 2. ANSYS 导出文件

新建模型时读入。由随软件提供的 Mechanical 脚本生成，放在同一个文件夹中，默认为桌面上的 `FAT_ANSYS`，新建模型时选这个文件夹。

| 文件 | 来源 | 内容 |
|---|---|---|
| `STEP_01_time_1.csv` … `STEP_12_time_12.csv` | 04 号脚本 | 每个载荷步评定面节点的 6 个应力分量：`body_id,node_id,SX,SY,SZ,SXY,SYZ,SXZ`，单位 MPa，坐标系 local |
| `export_info.txt` | 04 号脚本 | 导出设置、约束位置、焊缝截面位置 |
| `nodes_xyz.csv` | 05 号脚本 | 节点坐标，单位 mm |
| `surface_facets.csv` | 05 号脚本 | 表面面片，用于三维显示和表面法向 |
| `mesh_quality.csv`、`export_info_mesh.txt` | 05 号脚本 | 网格尺寸统计，用于数据检查 |
| `weld_profile_nodes.csv` 等 | 07 号脚本 | 焊缝子午截面，用于三维显示和几何核对，可不提供 |

要求：

- 评定面是焊趾 1 mm 圆角面，命名选择为 `FAT`；应力为节点平均值；同一模型各载荷步的节点集合相同。
- 管段模型 A、B 两端各施加 6 个单位载荷，力 1 kN、力矩 1 kN·m，载荷步结束时间为 1～12 s，顺序见 ANSYS 脚本说明。
- 坐标系 local 的 z 轴沿管轴，原点在管轴上。

自定义模型可以在新建模型对话框中逐步指定每个载荷步的施加位置、分量、方向、大小和对应的结果文件。

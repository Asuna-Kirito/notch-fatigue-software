# 常见问题

| 现象 | 原因与处理 |
|---|---|
| 双击 exe 没有反应或提示缺少 DLL | 从 Releases 重新下载压缩包解压；从 Code 下载的 ZIP 可能缺少 Git LFS 存放的 `llvmlite.dll`。确认系统是 64 位 Windows 10 或 11 |
| 杀毒软件拦截 | 打包程序偶尔被误报，把程序文件夹加入信任，或从 Releases 重新下载 |
| 放在 Program Files 下提示文件夹只读 | 软件把数据写在程序文件夹内，请放到 D 盘、桌面等可以写入的位置 |
| 第一次计算很慢 | 计算内核第一次运行时编译为本机代码，需要几十秒，以后有缓存 |
| 载荷文件提示缺少某些列 | 列名识别不了，点“列对照”指定各列和单位，见 [输入文件格式](输入文件格式.md) |
| 数据检查中“两端工况一致性”偏大 | 单位载荷模型有误，检查载荷步顺序、方向、施加端和约束位置 |
| 数据检查中“表面法向识别”偏大 | 导出的节点不在表面上，或没有做节点平均 |
| 结果页提示超出适用范围 | 焊缝名义应力超过屈服强度，或应力范围超过 1.5 倍屈服强度，缺口应力法不适用，需要复核载荷 |
| 节点页提示节点不存在 | 该节点不在当前结果的焊趾节点中，核对节点号或切换结果 |
| 三维页空白或报 OpenGL 错误 | 显卡驱动不支持 OpenGL 2.0，远程桌面下常见，其他页面不受影响 |
| 界面太大或太小 | 左下角“界面缩放”选 80 %～150 %，重启后生效 |
| 怎样升级 | 把旧版本 `_internal\数据` 中的模型、结果和 `材料与曲线库.json` 复制到新版本对应位置 |
| 怎样卸载 | 运行 `卸载.cmd` 或直接删除程序文件夹，软件不写注册表，也不在系统目录留文件 |
| Linux 提示 `could not load the Qt platform plugin "xcb"` | 缺少 Qt 运行库，运行 `sudo apt install libxcb-cursor0 libegl1 libgl1 libxkbcommon-x11-0` |
| Linux 双击没有反应 | 在终端运行 `./焊缝缺口应力疲劳分析` 查看提示；用 `tar -xzf` 解压以保留文件权限 |
| Linux 提示 `GLIBC_2.35 not found` | 系统太旧，需要 Ubuntu 22.04、Debian 12 或更新的发行版 |

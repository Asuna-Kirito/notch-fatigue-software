# 常见问题

| 现象 | 原因与处理 |
|---|---|
| 双击 exe 没有反应或报缺少 DLL | 用 Release 压缩包重新解压（从 Code 下载的 ZIP 可能缺少 LFS 大文件 `llvmlite.dll`）；确认是 64 位 Windows 10 / 11 |
| 杀毒软件拦截 | 打包程序偶尔被误报，把程序文件夹加入信任，或从 Release 重新下载 |
| 放在“Program Files”下提示文件夹只读 | 软件把数据写在程序文件夹内，放到有写权限的位置，如 D:\ 或桌面 |
| 第一次计算很慢 | 计算内核第一次运行时编译为本机代码，需要几十秒，之后有缓存 |
| 载荷文件提示缺少某些列 | 列名无法识别，点 **列对照…** 指定各列和单位，见 [输入文件格式](输入文件格式.md) |
| 数据检查中“两端工况一致性”偏大 | 单位载荷库有误：检查载荷步顺序、方向、施加端和约束位置 |
| 数据检查中“表面法向识别”偏大 | 导出的节点不在表面，或没有做节点平均 |
| 结果页提示超出适用范围 | 焊缝名义应力超过屈服强度或范围超过 1.5 倍屈服强度，缺口应力法不适用，需复核载荷 |
| 节点页提示节点不存在 | 该节点不在当前结果的焊趾节点中，核对节点号或切换结果 |
| 三维页空白或报 OpenGL 错误 | 显卡驱动不支持 OpenGL 2.0（远程桌面常见），其余页面不受影响 |
| 界面太大或太小 | 左下角“界面缩放”选 80 %～150 %，重启后生效 |
| 怎样升级 | 把旧版本 `_internal\数据` 中的模型、结果、`材料与曲线库.json` 复制到新版本对应位置 |
| 怎样卸载 | 运行 `卸载.cmd` 或直接删除程序文件夹；软件不写注册表、不在系统目录留文件 |

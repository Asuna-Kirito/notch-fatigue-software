# 平台支持

| 平台 | 处理器 | 状态 |
|---|---|---|
| Windows 11 64 位 | Intel / AMD x86-64 | 已提供，已测试 |
| Windows 10 64 位（1809 及以上） | Intel / AMD x86-64 | 已提供（同一发布包） |
| Linux 64 位（glibc 2.35 及以上：Ubuntu 22.04 及以上、Debian 12 及以上等） | Intel / AMD x86-64 | 已提供（1.0.1 起），单独的 tar.gz 发布包 |
| ARM 架构（Windows ARM、Linux ARM64） | ARM64 | 不提供 |
| Windows 7 / 8 / 8.1、32 位系统 | — | 不支持 |
| macOS | — | 不支持 |

说明：

- Linux 版在 Ubuntu 22.04 上打包，打包后自动运行自检（用内置模型完成一次计算并生成 Word 报告）。glibc 低于 2.35 的旧系统（如 CentOS 7、Ubuntu 20.04）不能运行。
- Linux 版需要图形桌面（X11 或 Wayland）。缺少 Qt 运行库时先安装（Ubuntu / Debian）：
  `sudo apt install libxcb-cursor0 libegl1 libgl1 libxkbcommon-x11-0`；三维页需要 OpenGL 驱动。
- Linux 上没有微软雅黑时，界面使用软件自带的 Noto Sans SC 字体；导出的 Word 报告用 WPS 或 LibreOffice 打开。
- Windows 11 ARM 电脑可用系统自带的 x64 仿真运行 Windows x64 版，但不作为支持的平台。

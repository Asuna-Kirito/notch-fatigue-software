# 平台支持

| 平台 | 处理器 | 状态 |
|---|---|---|
| Windows 11 64 位 | Intel / AMD x86-64 | 已提供，已测试 |
| Windows 10 64 位（1809 及以上） | Intel / AMD x86-64 | 已提供（同一发布包） |
| Windows 11 ARM | ARM64 | 原生版尚未提供；可用 Windows 11 自带的 x64 仿真运行 x64 版 |
| Linux 64 位（如 Ubuntu 22.04 及以上） | x86-64 | 尚未提供 |
| Linux 64 位 | ARM64（aarch64） | 尚未提供 |
| Windows 7 / 8 / 8.1、32 位系统 | — | 不支持 |
| macOS | — | 不支持 |

说明：

- 发布包用 PyInstaller 打包，不能跨平台生成，每个“系统 + 处理器”组合要在对应的电脑上单独打包。软件的各依赖库都有 Linux x64、Linux ARM64 和 Windows ARM64 版本，
  打包脚本已经准备好，相应平台的发布包完成测试后会在 Releases 中提供。
- Linux 版运行时需要 Qt 的 xcb 相关库（如 `libxcb-cursor0`），三维页需要 OpenGL 驱动。

# 计算方法简介

完整的原理、公式和验证见软件内帮助页的技术手册。

## 1. 有效缺口应力法

IIW 有效缺口应力法把焊趾的实际形状换成半径 1 mm 的虚拟圆角，在有限元模型中直接计算圆角表面的应力，
用一条与接头形式无关的 S-N 曲线评定：钢的最大主应力为 FAT225，即 2×10⁶ 次对应 225 MPa，斜率 m = 3；剪应力为 FAT160，m = 5。
网格要求为二次单元，圆角处单元尺寸不大于半径的四分之一。

## 2. 单位载荷叠加

线弹性条件下，焊趾节点的应力是焊缝截面 6 个内力的线性组合，6 个内力为剪力 Fx、Fy，轴力 Fz，弯矩 Mx、My，扭矩 Mz：

```
σ(t) = Σ_j R_j(t) · G_j
```

G_j 为单位截面内力引起的节点应力张量，由 ANSYS 单位载荷工况求出；R_j(t) 为 OrcaFlex 给出的焊缝截面内力时程。
每个节点得到 6 个应力分量的完整时程，不需要逐时刻做有限元计算。

## 3. 方向搜索与雨流计数

应力投影到焊趾表面的切平面上，自由表面上法向应力为 0。在切平面内对每个方向的正应力时程按 ASTM E1049 做雨流计数，
按 S-N 曲线求损伤，损伤最大的方向为评定方向。一段记录默认视为重复的载荷块，循环全部闭合。

## 4. 应力状态与评定方法

| 状态 | 判据 | 采用方法 |
|---|---|---|
| 单轴主导 | 剪应力幅不超过正应力幅的 15 % | 主应力法 |
| 剪切主导 | 正应力幅不超过剪应力幅的 15 % | 剪应力法 |
| 比例多轴 | 主方向转动范围小于 20° | 主应力法与 IIW 正剪组合取小 |
| 非比例多轴 | 主方向转动范围不小于 20° | IIW 正剪组合，CV = 0.5；可选 MWCM |

缺口 von Mises 应力超过屈服强度时，另用 Neuber 修正和 SWT 应变寿命法校核，默认与 S-N 结果取小。

## 5. 损伤累积与寿命

按 Miner 线性累积。寿命小时数等于允许损伤和 D 除以一段记录的损伤，再乘记录时长。
D 可选 IIW 变幅载荷 0.5、DNV 立管设计疲劳系数 3、6、10 对应的 1/DFF、与试验对比时的 1.0，或自定义。
给出每年作用时间和设计年限时，同时给出年寿命。

## 6. S-N 曲线

| 环境 | 正应力曲线 | 依据 |
|---|---|---|
| 空气 · IIW | FAT225，m = 3，10⁷ 次后 m = 5 | IIW 第三版 |
| 海水 · IIW 70 % | 疲劳强度乘 0.7，无拐点 | IIW §3.5.5 |
| 海水+阴极保护 · DNV | log a = 12.958，m = 3；10⁶ 次后 log a = 17.596，m = 5 | DNV-RP-C203 表 E-1 |
| 海水自由腐蚀 · DNV | log a = 12.880，m = 3，单斜率 | DNV-RP-C203 表 E-1 |

## 7. 坐标约定

z 轴为管轴，由 A 端指向 B 端，A 端为 OrcaFlex 中弧长较小的一端；壁张力拉为正。ANSYS 模型的 local 坐标系与之一致即可。
绕管轴的转角、坐标镜像、内力整体反号都不改变最小寿命，只改变危险点的周向位置。
